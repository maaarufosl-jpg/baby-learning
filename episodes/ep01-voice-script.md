# পর্ব ১: বিসমিল্লাহ বলে খাই — কণ্ঠ রেকর্ডের স্ক্রিপ্ট

এই ফাইলটা ভিডিওর ডেটা থেকে স্বয়ংক্রিয়ভাবে তৈরি। দৃশ্যের লেখা বা সময় বদলালে আবার তৈরি করুন:

```bash
cd video && node scripts/voice-script.mjs ep01 > ../episodes/ep01-voice-script.md
```

## রেকর্ড করার নিয়ম

1. শান্ত ঘরে রেকর্ড করুন। ফোনের ভয়েস রেকর্ডারই যথেষ্ট, মুখ থেকে এক বিঘত দূরে রাখুন।
2. প্রতিটা লাইন আলাদা ফাইলে রাখুন। নিচের টেবিলের ফাইলের নাম হুবহু ব্যবহার করুন।
3. ধীরে বলুন, স্বাভাবিক কথার চেয়ে একটু আস্তে। বাচ্চারা যেন প্রতিটা শব্দ বুঝতে পারে।
4. প্রতিটা ফাইলের শুরু ও শেষে আধা সেকেন্ড নীরবতা রাখুন।
5. "সর্বোচ্চ সময়" কলামটা শুধু ধারণার জন্য। লাইন একটু লম্বা হলে সমস্যা নেই, ভিডিওর সময় কণ্ঠ অনুযায়ী মিলিয়ে নেওয়া হবে।
6. দোয়ার লাইনগুলো এমন কেউ রেকর্ড করবেন যার উচ্চারণ সঠিক। প্রকাশের আগে একজন আলেম বা ক্বারীকে শুনিয়ে নিন।
7. "এবার তুমি বলো" অংশের নীরবতা রেকর্ড করতে হবে না, ভিডিওতে তা আগে থেকেই আছে।

রেকর্ড শেষ হলে ফাইলগুলো `video/public/audio/ep01/` ফোল্ডারে রাখুন, অথবা আমাকে পাঠান। আমি ভিডিওর সাথে জুড়ে প্রতিটা দৃশ্যের সময় কণ্ঠ অনুযায়ী মিলিয়ে দেব।
