## ইউটিউব: চ্যানেলের বর্ণনা

```
আসসালামু আলাইকুম! 🌙

"ছোট্ট মুমিন" হলো ২ থেকে ৫ বছরের সোনামণিদের জন্য গল্পে গল্পে দোয়া আর সুন্নাহ শেখার চ্যানেল।

প্রতিটা পর্বে উমায়ের, তার ছোট বোন সাফা, মা আর তাদের আদুরে বিড়ালছানা মিউয়ের সাথে একটা ছোট্ট গল্প। গল্পের ভেতরেই শেখানো হয় একটা দোয়া আর একটা সুন্নাহ, যেমন খাওয়ার আগে বিসমিল্লাহ, খাওয়ার পর আলহামদুলিল্লাহ, ঘুমের দোয়া, সালাম দেওয়া।

✔ সহজ বাংলা, ধীরে ধীরে বলা
✔ দোয়া ভেঙে ভেঙে শেখানো, বাচ্চা নিজেও বলতে পারে
✔ আরবি, বাংলা উচ্চারণ আর অর্থ স্ক্রিনে
✔ প্রতিটা দোয়ার সাথে হাদিসের সূত্র
✔ কোনো বাদ্যযন্ত্র নেই
✔ কোনো ভয় দেখানো নেই, শুধু ভালোবাসা দিয়ে শেখানো

আপনার সোনামণির পাশে বসে একসাথে দেখুন। খাওয়ার সময়, ঘুমের আগে, যখনই সুযোগ পান, একসাথে দোয়াটা বলুন। ইনশাআল্লাহ ছোট ছোট অভ্যাস থেকেই বড় হবে একজন মুমিন।

নতুন পর্ব পেতে সাবস্ক্রাইব করুন। 🤍
```

## ফেসবুক: পেজের ছোট পরিচিতি (Intro, ১০১ অক্ষরের মধ্যে)

```
২-৫ বছরের সোনামণিদের জন্য গল্পে গল্পে দোয়া ও সুন্নাহ শেখা। বাদ্যযন্ত্র ছাড়া, সহজ বাংলায়।
```

## ফেসবুক: পেজের বিস্তারিত (About)

```
"ছোট্ট মুমিন" বাবা-মায়েদের জন্য একটি পেজ, যেখানে ছোট বাচ্চাদের উপযোগী ইসলামিক কার্টুন গল্প পাবেন।

প্রতিটা পর্বে উমায়ের, সাফা, মা আর বিড়ালছানা মিউয়ের গল্পের মাধ্যমে শেখানো হয় একটি দোয়া ও একটি সুন্নাহ। দোয়া ভেঙে ভেঙে ধীরে শেখানো হয়, স্ক্রিনে থাকে আরবি, বাংলা উচ্চারণ, অর্থ আর হাদিসের সূত্র। ভিডিওতে কোনো বাদ্যযন্ত্র নেই।

আপনার সোনামণির সাথে বসে দেখুন, আর দিনের কাজের সময় একসাথে দোয়াগুলো বলার অভ্যাস করুন।
```

পেজের ধরন: Education। ফেসবুকে ১৩ বছরের কম বয়সী কেউ থাকে না, তাই পোস্টের লেখা বাবা-মায়েদের উদ্দেশে লিখবেন।

## পর্ব ১: ভিডিওর বর্ণনা

```
উমায়েরের খুব খিদে পেয়েছে, কিন্তু তাড়াহুড়োয় সে একটা জিনিস ভুলে গেছে! মা এসে শেখান খাওয়ার আগের ছোট্ট দোয়া আর নবীজি ﷺ এর তিনটি সুন্নাহ।

আজকের দোয়া: بِسْمِ اللَّهِ (বিসমিল্লাহ)
অর্থ: আল্লাহর নাম নিয়ে শুরু করছি

আজকের সুন্নাহ:
১. খাওয়ার আগে বিসমিল্লাহ বলা
২. ডান হাতে খাওয়া
৩. নিজের সামনে থেকে খাওয়া

সূত্র: সহিহ বুখারি ৫৩৭৬, সহিহ মুসলিম ২০২২

বাবা-মায়ের জন্য টিপস:
১. আজ প্রতিবার খাওয়ার আগে সোনামণিকে জিজ্ঞেস করুন, "খাওয়ার আগে কী বলি?" উত্তর নিজে দেবেন না, একটু অপেক্ষা করুন।
২. বললে হাসিমুখে বলুন "মাশাআল্লাহ!" ভুলে গেলে রাগ নয়, শুধু নিজে জোরে বিসমিল্লাহ বলুন।

এই ভিডিওতে কোনো বাদ্যযন্ত্র ব্যবহার করা হয়নি।

```
