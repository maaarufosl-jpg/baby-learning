# নিদর্শন: প্রকৃতির মাঝে ছোট ইসলামিক রিলস

ফেসবুক রিলস আর ইউটিউব শর্টসের জন্য ১৫–৩০ সেকেন্ডের খাড়া (১০৮০×১৯২০) ভিডিও।
কোনো মানুষ, প্রাণী বা কার্টুন নেই; শুধু প্রকৃতি। কোনো মিউজিক নেই; শুধু প্রকৃতির শব্দ আর কণ্ঠ।

চার ধরনের রিল: আল্লাহর সুন্দর নাম · ছেলে-মেয়েদের ইসলামিক নাম · ছোট আয়াত · ছোট সহিহ হাদিস।

## কোথায় কী

| ফাইল | কী আছে |
|---|---|
| `docs/brand.md` | সিরিজের নাম, লোগো আর রঙের তিনটি প্রস্তাব |
| `docs/reels-list.md` | প্রথম ১২টি রিলের তালিকা, সূত্রসহ |
| `docs/reel01.md` … `docs/reel12.md` | প্রতিটি রিলের পরিকল্পনা: Gemini প্রম্পট, সময় ধরে লেখা ও কণ্ঠ, সূত্র, আলেমের যাচাই-তালিকা |
| `docs/preview/` | লোগো আর রিল ১ এর নমুনা ছবি |
| `src/data/reels.ts` | সব রিলের আসল লেখা (আরবি, অর্থ, সূত্র, প্রম্পট) — এক জায়গায় |

## আপনার কাজ (শুধু কপি, পেস্ট আর পাঠানো)

1. `docs/reelNN.md` থেকে "দৃশ্য ১" এর প্রম্পট কপি করে Gemini-তে দিন (খাড়া 9:16)।
2. ভিডিওটা চ্যাটে পাঠান, লিখুন যেমন: "রিল ১, দৃশ্য ১"।
3. দৃশ্য ২ ও ৩ একইভাবে।
4. চাইলে আরবি অংশ কারো কণ্ঠে রেকর্ড করে পাঠান ("রিল ১, আরবি")। না পাঠালে আরবি শুধু লেখায় থাকবে।
5. আমি নমুনা দেখাব; আপনি "রেন্ডার করো" বললে চূড়ান্ত ভিডিও বানাব।
6. প্রকাশের আগে আলেমকে `docs/reelNN.md` এর যাচাই-তালিকা দেখিয়ে নিন।

## কারিগরি অংশ (Claude এগুলো চালায়)

```bash
npm install
npm run attach reel01      # public/clips/reel01/scene1.mp4 … আর public/audio/reel01/arabic.m4a প্রস্তুত করে
npm run narrate reel01     # ElevenLabs দিয়ে বাংলা বর্ণনা (ELEVENLABS_API_KEY পরিবেশ থেকে নেয়; ফাইলে কখনো রাখা হয় না)
npm run docs               # src/data/reels.ts থেকে docs/ আবার লেখে
npm run brand              # লোগোর তিন বিকল্পের ছবি
npm run render reel01      # চূড়ান্ত ভিডিও out/reel01.mp4 (তিনটি দৃশ্য না থাকলে থামবে; নমুনার জন্য --draft)
npm run studio             # ব্রাউজারে দেখা
```

ক্রোম না থাকলে: `REMOTION_BROWSER_EXECUTABLE=/path/to/headless_shell npm run render reel01`।

বর্ণনার কণ্ঠ: ElevenLabs `eleven_v3` মডেল, ধীর গতি (০.৯)। আরবি লেখা কখনো AI কণ্ঠে পাঠানো হয় না; স্ক্রিপ্ট আরবি অক্ষর পেলে থেমে যায়।
