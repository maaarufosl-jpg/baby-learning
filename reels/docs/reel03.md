# রিল ৩: কষ্টের সাথেই স্বস্তি

ধরন: ছোট আয়াত · দৈর্ঘ্য: প্রায় ২৪ সেকেন্ড · খাড়া ১০৮০×১৯২০ · তিনটি ৮ সেকেন্ডের প্রকৃতির দৃশ্য

## দৃশ্য (কোডে আঁকা প্রকৃতি, কোনো মানুষ বা প্রাণী নেই)

| দৃশ্য | কী দেখা যাবে | শব্দ |
|---|---|---|
| ১ | পাহাড়ের ওপর ঘন ধূসর মেঘ, ধীরে চলছে | পাহাড়ি বাতাস, দূরে একবার হালকা মেঘের গর্জন |
| ২ | মেঘ সরে যাচ্ছে, ফাঁক দিয়ে সূর্যের আলোর রেখা নামছে | ঘাসের ওপর বাতাস |
| ৩ | বৃষ্টির পর সবুজ উপত্যকার ওপর রংধনু | ভোরের হালকা বাতাস, দূরে পাখির ডাক |

## পর্দায় ও কণ্ঠে যা থাকবে

| সময় | কী | বিষয় |
|---|---|---|
| ০:০০ | লেখা | ছোট আয়াত · ১ |
| ০:০০ | কণ্ঠ | কঠিন সময়ে মনে রাখার মতো একটি আয়াত। |
| ০:০৩ | লেখা | إِنَّ مَعَ الْعُسْرِ يُسْرًا |
| ০:০৪ | আরবি কণ্ঠ | إِنَّ مَعَ الْعُسْرِ يُسْرًا (মানুষের রেকর্ড, না থাকলে শুধু লেখা) |
| ০:০৯ | লেখা | নিশ্চয়ই কষ্টের সাথেই আছে স্বস্তি। |
| ০:০৯ | কণ্ঠ | নিশ্চয়ই কষ্টের সাথেই আছে স্বস্তি। |
| ০:১৪ | লেখা | সূরা আশ-শারহ, আয়াত ৬ (৯৪:৬) |
| ০:১৪ | কণ্ঠ | সূরা আশ-শারহ, ছয় নম্বর আয়াত। |
| ০:১৭ | লেখা | ঠিক আগের আয়াতেও (৯৪:৫) একই কথা এসেছে |
| ০:১৭ | কণ্ঠ | আল্লাহ কথাটি পরপর দুবার বলেছেন। |
| ০:২১ | লেখা | শেষ কার্ড: লোগো, সিরিজের নাম, "পরের রিল দেখতে ফলো করুন" |

পুরো সময় দৃশ্যের ওপর নরম অন্ধকার স্তর থাকবে, ওপরে ছোট লোগো। প্রকৃতির শব্দ বাজবে, কণ্ঠের সময় একটু কমে যাবে।

## সূত্র

- সূরা আশ-শারহ (আল-ইনশিরাহ) ৯৪:৬; আগের আয়াত ৯৪:৫ — فَإِنَّ مَعَ الْعُسْرِ يُسْرًا

## আলেমের যাচাই-তালিকা

- [ ] আয়াতের আরবি ও হরকত মুসহাফের সাথে মিলানো: إِنَّ مَعَ الْعُسْرِ يُسْرًا
- [ ] বাংলা অর্থ
- [ ] সূরার নাম ও আয়াত নম্বর ৯৪:৬
- [ ] নোট "আগের আয়াতেও একই কথা" ঠিক আছে কি না
- [ ] দৃশ্যে কোনো মানুষ, প্রাণী বা পাখি নেই (দৃশ্যগুলো কোডে আঁকা)
- [ ] প্রকৃতির শব্দে (AI দিয়ে তৈরি) কোনো বাদ্যযন্ত্র বা গানের মতো সুর নেই
- [ ] বাংলা বর্ণনার (AI কণ্ঠ) প্রতিটি বাক্য শুনে ঠিক আছে
- [ ] আরবি কণ্ঠ থাকলে উচ্চারণ ও তাজবিদ ঠিক আছে

## যেখানে আমি পুরো নিশ্চিত নই

- বিশেষ কোনো অনিশ্চয়তা নেই, তবুও উপরের তালিকা ধরে যাচাই করুন।
