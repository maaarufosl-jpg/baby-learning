# রিল ৫: আল-খালিক: সৃষ্টিকর্তা

ধরন: আল্লাহর সুন্দর নাম · দৈর্ঘ্য: প্রায় ২৪ সেকেন্ড · খাড়া ১০৮০×১৯২০ · তিনটি ৮ সেকেন্ডের প্রকৃতির দৃশ্য

## দৃশ্য (কোডে আঁকা প্রকৃতি, কোনো মানুষ বা প্রাণী নেই)

| দৃশ্য | কী দেখা যাবে | শব্দ |
|---|---|---|
| ১ | ভোরের আলোয় বরফঢাকা পাহাড়চূড়া | পাহাড়ি বাতাস, দূরে একবার হালকা মেঘের গর্জন |
| ২ | বাতাসে দোলা রঙিন বুনো ফুলের মাঠ | ঘাসের ওপর বাতাস |
| ৩ | পাহাড়ের ওপর তারাভরা রাতের আকাশ, ছায়াপথ ধীরে ঘুরছে | শান্ত রাতের বাতাস |

## পর্দায় ও কণ্ঠে যা থাকবে

| সময় | কী | বিষয় |
|---|---|---|
| ০:০০ | লেখা | আল্লাহর সুন্দর নাম · ২ |
| ০:০০ | কণ্ঠ | আল্লাহর সুন্দর নামগুলোর একটি। |
| ০:০৩ | লেখা | الْخَالِقُ |
| ০:০৪ | আরবি কণ্ঠ | الْخَالِقُ (মানুষের রেকর্ড, না থাকলে শুধু লেখা) |
| ০:০৫ | লেখা | আল-খালিক |
| ০:০৮ | লেখা | সৃষ্টিকর্তা |
| ০:০৮ | কণ্ঠ | এর অর্থ, সৃষ্টিকর্তা। |
| ০:১১ | লেখা | যিনি সবকিছু অস্তিত্বে এনেছেন |
| ০:১১ | কণ্ঠ | পাহাড়, ফুল আর তারা, সবই তাঁর সৃষ্টি। |
| ০:১৬ | লেখা | هُوَ اللّٰهُ الْخَالِقُ الْبَارِئُ الْمُصَوِّرُ |
| ০:১৬ | কণ্ঠ | সূরা আল-হাশরের চব্বিশ নম্বর আয়াতে এই নাম এসেছে। |
| ০:১৭ | লেখা | তিনিই আল্লাহ, সৃষ্টিকর্তা, উদ্ভাবক, রূপদাতা |
| ০:১৭ | লেখা | সূরা আল-হাশর ৫৯:২৪ (আয়াতের অংশ) |
| ০:২১ | লেখা | শেষ কার্ড: লোগো, সিরিজের নাম, "পরের রিল দেখতে ফলো করুন" |

পুরো সময় দৃশ্যের ওপর নরম অন্ধকার স্তর থাকবে, ওপরে ছোট লোগো। প্রকৃতির শব্দ বাজবে, কণ্ঠের সময় একটু কমে যাবে।

## সূত্র

- সূরা আল-হাশর ৫৯:২৪ — هُوَ اللّٰهُ الْخَالِقُ الْبَارِئُ الْمُصَوِّرُ لَهُ الْأَسْمَاءُ الْحُسْنٰى

## আলেমের যাচাই-তালিকা

- [ ] নামের আরবি ও হরকত: الْخَالِقُ
- [ ] আয়াতাংশের আরবি মুসহাফের সাথে মিলানো
- [ ] অর্থ: সৃষ্টিকর্তা · আল-বারি = উদ্ভাবক · আল-মুসাওয়ির = রূপদাতা
- [ ] সূত্র ৫৯:২৪
- [ ] দৃশ্যে কোনো মানুষ, প্রাণী বা পাখি নেই (দৃশ্যগুলো কোডে আঁকা)
- [ ] প্রকৃতির শব্দে (AI দিয়ে তৈরি) কোনো বাদ্যযন্ত্র বা গানের মতো সুর নেই
- [ ] বাংলা বর্ণনার (AI কণ্ঠ) প্রতিটি বাক্য শুনে ঠিক আছে
- [ ] আরবি কণ্ঠ থাকলে উচ্চারণ ও তাজবিদ ঠিক আছে

## যেখানে আমি পুরো নিশ্চিত নই

- শব্দে ঝিঁঝিঁর ডাক রেখেছি (কীটপতঙ্গ দেখা যাবে না)। না চাইলে প্রম্পট থেকে "soft crickets" মুছে দেবো।
