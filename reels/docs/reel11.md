# রিল ১১: আমাকে স্মরণ করো

ধরন: ছোট আয়াত · দৈর্ঘ্য: প্রায় ২৪ সেকেন্ড · খাড়া ১০৮০×১৯২০ · তিনটি ৮ সেকেন্ডের প্রকৃতির দৃশ্য

## দৃশ্য (কোডে আঁকা প্রকৃতি, কোনো মানুষ বা প্রাণী নেই)

| দৃশ্য | কী দেখা যাবে | শব্দ |
|---|---|---|
| ১ | পাহাড়ি হ্রদের ওপর তারাভরা রাতের আকাশ | শান্ত রাতের বাতাস |
| ২ | চাঁদের আলোয় ধীরে ভেসে যাওয়া মেঘ | শান্ত রাতের বাতাস |
| ৩ | ভোরের আগে দিগন্তে প্রথম আলো (ফজরের সময়) | ভোরের হালকা বাতাস, দূরে পাখির ডাক |

## পর্দায় ও কণ্ঠে যা থাকবে

| সময় | কী | বিষয় |
|---|---|---|
| ০:০০ | লেখা | ছোট আয়াত · ৩ |
| ০:০০ | কণ্ঠ | আল্লাহ তাআলা বলেন, |
| ০:০৩ | লেখা | فَاذْكُرُونِي أَذْكُرْكُمْ |
| ০:০৪ | আরবি কণ্ঠ | فَاذْكُرُونِي أَذْكُرْكُمْ (মানুষের রেকর্ড, না থাকলে শুধু লেখা) |
| ০:০৯ | লেখা | সুতরাং তোমরা আমাকে স্মরণ করো, আমিও তোমাদের স্মরণ করব। |
| ০:০৯ | কণ্ঠ | তোমরা আমাকে স্মরণ করো, আমিও তোমাদের স্মরণ করব। |
| ০:১৪ | লেখা | সূরা আল-বাকারা ২:১৫২ (আয়াতের অংশ) |
| ০:১৪ | কণ্ঠ | সূরা আল-বাকারা, একশো বাহান্ন নম্বর আয়াত। |
| ০:২১ | লেখা | শেষ কার্ড: লোগো, সিরিজের নাম, "পরের রিল দেখতে ফলো করুন" |

পুরো সময় দৃশ্যের ওপর নরম অন্ধকার স্তর থাকবে, ওপরে ছোট লোগো। প্রকৃতির শব্দ বাজবে, কণ্ঠের সময় একটু কমে যাবে।
