# প্রথম ১২টি রিল

চার ধরনের রিল পালা করে আসবে: সুন্দর নাম → ছোট দোয়া → আয়াত → হাদিস। প্রতিটির পুরো পরিকল্পনা `docs/reelNN.md` ফাইলে।
